# 오래곁에 (옛 이름 댕냥차트)

강아지·고양이의 산책, 밥, 약, 체중, 접종을 한 번 눌러 기록하고, 동물병원에 갈 때 최근 기록을 한 장으로 보여 주는 앱입니다.

## 지금 버전 (1차)

- 로그인 없이 휴대폰 브라우저(localStorage)에 저장. 홈 화면에 추가하면 앱처럼 열리고 오프라인에서도 열림
- 강아지·고양이 여러 마리 등록, 종류별 기록 버튼
- 아침밥·저녁밥 사료 선택, 간식 기록
- 병원용 요약을 이미지(PNG)로 저장·공유 (휴대폰은 공유창으로 카톡 바로 전송)
- 체중 그래프, 접종·예방 일정(간격은 보호자가 입력), 병원용 한 장 요약, 백업 파일 저장·불러오기
- 아이별 사진(증명사진 칸, 이 휴대폰에만 저장), 진료 차트 디자인
- 잠잘 때 호흡수 30초 세기(그래프·병원용 요약 반영), 일정 휴대폰 달력(.ics)에 넣기, 실제 한 날짜 고르기
- 약 남은 양(며칠분), 다니는 병원(전화 바로 걸기)
- 기록 시각 고르기(지금·30분·1시간·3시간 전·직접, 7일 이내), 마지막 기록 "N시간 전" 표시, 여러 아이 한 번에 밥 기록
- 나만의 기록 칸(목욕·양치·인슐린 등), 음수량(ml) 기록과 병원용 요약 반영
- 다음 단계: 가족 공유(서버 저장), 알림, 유료 기능

## 구조

- `public/`: 앱 파일 (index.html, app.js, style.css, sw.js, manifest, 아이콘)
- `build.mjs`: `public/`을 `dist/`로 복사하고 서비스워커 버전을 갱신 (외부 패키지 없음)
- `wrangler.jsonc`: Cloudflare Workers가 `dist/`를 정적 사이트로 올림

## Cloudflare 배포 설정

빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy` (기본값 그대로).

## 원칙

- 기록을 정리해 보여 줄 뿐 진단·처방 문구는 쓰지 않습니다.
- 실시간 GPS 위치 저장은 하지 않습니다 (위치정보법 신고 대상이 될 수 있음). 산책은 시간만 입력합니다.

## 방문·설치 숫자

- `https://(주소)/stats` 에서 홈 화면 설치 수, 방문 기기 수, 최근 14일 표를 봄
- `src/worker.js` 의 Durable Object(SQLite)에 저장. 브라우저가 만든 무작위 번호(localStorage `orae-anon`)만 받고 IP·기기정보·기록 내용은 저장하지 않음
